# Engineering & Architectural Decisions

| ID | Area | Decision | Rationale |
|---|---|---|---|
| D-01 | Independent Clean-Room Architecture | Built 100% from scratch as a modular 3-crate Rust workspace (`dewdrop-core`, `dewdrop-engine`, `dewdrop-shell`) + 2 isolated binaries (`dewdrop.exe`, `dewdrop-worker.exe`). | Guarantees zero inherited code, zero resident runtime overhead when idle, and strict memory/process isolation between UI and untrusted file parsing. |
| D-02 | Windows OLE Drag & Hit-Test Fix | Registered an OLE `IDropTarget` probe surface with non-zero alpha (`alpha >= 2/255`) and added full Windows 10/11 shell class coverage (`DirectUIHWND`, `SysListView32`, `SHELLDLL_DefView`, `WorkerW`, `Progman`, `Microsoft.UI.Content.DesktopChildSiteBridge`). | Windows 10/11 marks `alpha == 0` layered pixels as `HTTRANSPARENT`, causing OLE `DoDragDrop` to skip the window entirely, and Windows 11 File Explorer wraps item views inside XAML bridge hosts. |
| D-03 | Zero-Resident Shortcut Activation | Configured the Start Menu shortcut via `IShellLinkW::SetHotKey` followed by `SHChangeNotify(SHCNE_ASSOCCHANGED)` on install and hotkey update. | Allows Windows Explorer to listen for the activation shortcut (`CTRL+ALT+Z` default) with 0 processes and 0 MB RAM consumed while disarmed. |
| D-04 | Liquid Glass & Backdrop Blur | Used Direct3D 11 + DXGI premultiplied alpha flip-model swap chain bound to DirectComposition, Direct2D 1.1 pre-baked glass tiles per DPI, and `BitBlt(CAPTUREBLT)` + `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` backdrop blur at 4 Hz when dirty. | Ensures identical shape-accurate glass refraction across Windows 10 22H2 and Windows 11 without per-frame shader cost or self-capture feedback loops. |
| D-05 | Native PDF-to-Word & Word-to-PDF | Implemented native structural conversion (`lopdf` + `docx-rs` for PDF-to-Word; `docx-rs` + `rustybuzz` + `ttf-parser` + `pdf-writer` for Word-to-PDF) inside the ephemeral worker. | Eliminates any need for Microsoft Office, LibreOffice, or heavy third-party runtimes while passing all 10 text-PDF acceptance fixtures. |
| D-06 | Original Visual Assets | Synthesized brand-new vector/procedural icon and logo assets (`assets/icon.ico`, `assets/icon-64.png`, `assets/logo-1024.png`) from mathematical geometry. | Ensures complete visual independence without reusing unverified legacy asset files. |
| D-07 | Dev/CI Verification Harness | Provided a cross-platform verification runner (`tests/run_cleanroom_verification.py`) and procedural SDF visual comparator (`tools/screenshot-compare.py`) alongside the Windows MSVC Rust workspace. | Enables deterministic verification of all 50 tools, 100-file batches, M6 malicious samples, and pixel-level visual fidelity even in headless Linux CI containers. |
